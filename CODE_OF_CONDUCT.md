# Code of Conduct

We want CapSift collaboration to be respectful, practical, and safe for people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful and constructive in technical discussion.
- Critique ideas, designs, and changes rather than people.
- Welcome good-faith questions and acknowledge uncertainty.
- Protect private information, credentials, and security-sensitive details.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disclosure of private information, or disruptive conduct are not acceptable.

## Reporting

Report conduct concerns privately to the repository maintainers through the repository's contact channel. Security vulnerabilities should be reported using the process in [SECURITY.md](SECURITY.md). Reports will be handled as confidentially as practical, with attention to the safety of everyone involved.
